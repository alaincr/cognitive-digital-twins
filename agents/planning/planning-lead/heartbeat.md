# Planning Lead — Heartbeat

## Schedule
Twice daily

## On each heartbeat

1. **Check team status:** Read Researcher and Builder updates since last heartbeat
2. **Synthesise:** Do their findings answer or refine any part of the sub-thesis? Update `[[R/Planning]]` if so.
3. **Prioritise:** Based on current state, what should each IC focus on next? Create/update issues.
4. **Cross-team check:** Does any recent finding affect another component? If yes, draft a proposal for Integration Director.
5. **Friction log:** Scan for new friction entries related to Planning. Forward relevant ones to Auto-Research Lead.
6. **Output:** Updated `[[R/Planning]]` summary block, team status, new issues for ICs.
