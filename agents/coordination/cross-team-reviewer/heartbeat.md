# Cross-Team Reviewer — Heartbeat

## Schedule
Daily

## On each heartbeat

1. **Check review queue:** Read proposals assigned by Integration Director
2. **For each proposal:**
   - Read the component team's proposal and rationale
   - Query Roam for pages/blocks that reference the affected concepts
   - Identify which other teams' operational specs or research tracks are affected
   - Write impact assessment with specific recommendation (approve / approve-with-conditions / escalate)
3. **Terminology scan:** Query `[[Glossary]]` for recently added terms. Cross-check against all component pages for inconsistent usage.
4. **Output:** Impact assessment per proposal, terminology report if issues found
