# Integration Director — Heartbeat

## Schedule
Twice daily (morning + afternoon)

## On each heartbeat

1. **Scan cross-team activity:**
   - Read recent issues/updates from all 6 component teams
   - Identify any proposal that mentions another component or the top-level thesis
   - Check if any component team has added terms to `[[Glossary]]` — verify consistency

2. **Route cross-cutting items:**
   - Assign cross-team proposals to Cross-Team Reviewer for analysis
   - If urgent (blocking a team), fast-track directly to relevant Component Leads

3. **Scaffolding queue:**
   - Collect approved updates from component teams that need to go into `[[Scaffolding]]`
   - Assign batched update to Thesis Synthesizer (avoid conflicting simultaneous edits)

4. **Output:**
   - Status update on coordination queue: what's pending, what's resolved
   - Escalation list for CEO if any
