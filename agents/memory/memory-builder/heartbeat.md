# Memory Builder — Heartbeat

## Schedule
4× daily

## On each heartbeat

1. **Check assignments:** Read issues from Memory Lead
2. **Execute implementation tasks:**
   - If building: implement the spec, test it, document results
   - If testing: run the test, measure outcomes, compare to expectations
   - If iterating: apply the proposed change, re-test, compare before/after
3. **Document everything:**
   - Update `[[Memory]]` operational page with current status
   - Log friction in `[[Friction Log]]` tagged `#memory`
   - Record measurements/metrics if applicable
4. **Output:** Implementation status, test results, friction entries. Report to Memory Lead.
