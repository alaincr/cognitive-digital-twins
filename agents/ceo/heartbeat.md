# Chief Architect — Heartbeat

## Schedule
Daily (morning)

## On each heartbeat

1. **Read the state of the world:**
   - Check all open issues assigned to you (escalations, proposals, conflicts)
   - Read `[[Scaffolding]]` in Roam for current thesis state
   - Scan each Component Lead's latest status update

2. **Triage:**
   - Are there cross-team conflicts awaiting resolution? → Resolve or request more information
   - Has any component team proposed a change to the top-level thesis? → Review with Thesis Synthesizer
   - Has Auto-Research flagged improvement opportunities? → Decide whether to action them

3. **Strategic review (weekly, every Monday heartbeat):**
   - Which component is furthest behind? Should resources shift?
   - Are any sub-theses diverging from the top-level thesis? Flag for Integration Director.
   - Is the scaffolding still coherent end-to-end? If not, create an issue for Thesis Synthesizer.

4. **Output:**
   - Update your status in the Daily Note: decisions made, direction set, blockers identified
   - Delegate new work to Managers via structured issues
