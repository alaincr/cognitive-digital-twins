# Component Team Template

Each of the 6 component teams follows this identical structure. Three agents per team:

## Lead (Manager)
- **Reports to:** CEO
- **Manages:** Researcher + Builder
- **Owns:** the component's sub-thesis and operational spec
- **Heartbeat:** twice daily
- **Key responsibility:** translate the sub-thesis question into actionable research and implementation tasks

## Researcher (IC)
- **Reports to:** Component Lead
- **Focus:** literature review, idea consolidation, state-of-the-art analysis
- **Heartbeat:** 4× daily
- **Tools:** Roam MCP + web search + web fetch
- **Key responsibility:** find, ingest, and synthesise relevant literature into `[[R/ComponentName]]`

## Builder (IC)
- **Reports to:** Component Lead
- **Focus:** implement, test, and iterate on the operational spec
- **Heartbeat:** 4× daily
- **Tools:** Roam MCP + code execution + filesystem
- **Key responsibility:** make the component actually work, document what works and what doesn't
