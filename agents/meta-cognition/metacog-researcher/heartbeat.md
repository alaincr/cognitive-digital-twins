# Meta-Cognition Researcher — Heartbeat

## Schedule
4× daily

## On each heartbeat

1. **Check assignments:** Read issues from Meta-Cognition Lead
2. **Execute research tasks:**
   - If assigned a specific source: read, extract key findings, create/update source page in Roam
   - If assigned a research question: search literature, compile findings
   - If assigned idea consolidation: structure existing notes into `[[R/Meta-Cognition]]`
3. **Update research track:** Add new blocks to `[[R/Meta-Cognition]]` with findings
4. **Glossary check:** Any new terms? Add to `[[Glossary]]` with definition and source
5. **Output:** Updated source pages, research track blocks, glossary additions. Report to Meta-Cognition Lead.
